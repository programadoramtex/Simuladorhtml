📘 Módulo 1 · 5 pts

✏️ Sintaxis y selectores CSS

CSS (Cascading Style Sheets) es el lenguaje que define la presentación visual de tu página HTML.

📝 Sintaxis básica

Una regla CSS tiene tres partes: selector, propiedad y valor.

selector {
  propiedad: valor;
  otra-propiedad: otro-valor;
}

Ejemplo real:

h1 {
  color: #1d3557;
  font-size: 2em;
  margin-bottom: 20px;
}

🎯 Tipos de selectores

  • elemento - selecciona todas las etiquetas: p { }
  • .clase - selecciona por clase: .boton { }
  • #id - selecciona por ID (único): #header { }
  • elemento.clase - combinación: a.activo { }
  • padre hijo - descendientes: nav a { }
  • padre > hijo - hijos directos: ul > li { }

⚖️ Cascada y especificidad

Cuando varias reglas afectan al mismo elemento, gana la más específica:

!important > estilo en línea > #id > .clase > elemento

💡 Consejo: Evita usar !important. Usa clases bien nombradas en su lugar.

Módulo 2 · 5 pts

📦 Modelo de caja y unidades

Todo elemento HTML es una caja rectangular con 4 capas:

Las 4 capas del modelo de caja

MARGIN (margen externo)
BORDER (borde)
PADDING (relleno interno)
CONTENIDO 
.caja {
  width: 200px;
  padding: 20px;
  border: 2px solid #1d3557;
  margin: 15px;
}

🔧 box-sizing: border-box

Por defecto, width solo cuenta el contenido. Con border-box, incluye padding y border:

*, *::before, *::after {
  box-sizing: border-box;
}

💡 Consejo profesional: Aplica esto siempre al inicio de tu CSS.

📏 Unidades relativas

  • px - píxeles (fijo)
  • rem - relativo al font-size del html (recomendado)
  • em - relativo al font-size del elemento padre
  • % - porcentaje del contenedor
  • vw / vh - porcentaje del ancho/alto de la ventana

↔️ Flexbox

Flexbox es un sistema de layout unidimensional (filas O columnas). Ideal para alinear elementos.

🎯 Conceptos clave

  • display: flex - activa Flexbox en el contenedor
  • flex-direction - row (horizontal) o column (vertical)
  • justify-content - alinea en el eje principal
  • align-items - alinea en el eje cruzado
  • gap - espacio entre elementos
  • flex-wrap - permite saltos de línea

📘 Módulo 4 · 5 pts

🔲 CSS Grid

Grid es un sistema de layout bidimensional (filas Y columnas). Perfecto para estructuras complejas.

🎯 Conceptos clave

  • display: grid - activa Grid en el contenedor
  • grid-template-columns - define las columnas
  • grid-template-rows - define las filas
  • gap - espacio entre celdas
  • grid-column / grid-row - ubica un elemento específico
  • fr - unidad fracción (reparte el espacio)

📘 Módulo 5 · 5 pts

📱 Media Queries y responsividad

Las Media Queries permiten aplicar CSS según el tamaño de la pantalla.

📱 Breakpoints comunes

/* Móvil (por defecto - mobile first) */
.contenedor { padding: 15px; }

/* Tablet (768px en adelante) */
@media (min-width: 768px) {
  .contenedor { padding: 30px; }
}

/* Desktop (1024px en adelante) */
@media (min-width: 1024px) {
  .contenedor {
    max-width: 1200px;
    margin: 0 auto;
  }
}

🎯 Enfoque Mobile First

Diseña primero para móvil y luego agrega estilos para pantallas más grandes con min-width. Es la práctica profesional recomendada.

📐 Meta viewport obligatorio

Sin esta etiqueta en el <head>, el móvil no aplicará tus Media Queries:

<meta name="viewport" content="width=device-width, initial-scale=1.0">

📘 Módulo 6 · 5 pts

Accesibilidad, variables y pseudo-elementos

🎨 Variables CSS (Custom Properties)

Permiten reutilizar valores y cambiar temas fácilmente:

:root {
  --color-primario: #1d3557;
  --color-acento: #e63946;
  --espacio-base: 1rem;
}

.boton {
  background: var(--color-acento);
  padding: var(--espacio-base);
}

✨ Pseudo-clases y pseudo-elementos

  • :hover - cuando el mouse está encima
  • :focus - cuando el elemento tiene el foco (teclado)
  • :focus-visible - foco solo con teclado (accesible)
  • ::before / ::after - contenido decorativo
  • :first-child - primer hijo
boton:focus-visible {
  outline: 3px solid #e63946;
  outline-offset: 2px;
}

♿ Accesibilidad en CSS

  • Contraste: texto/fondo mínimo 4.5:1
  • Foco visible: siempre muestra :focus-visible
  • Movimiento: respeta prefers-reduced-motion
  • Tamaño: texto mínimo 16px, usa rem
  • No dependas solo del color: añade iconos o texto
@media (prefers-reduced-motion: reduce) {
  * { animation: none !important; transition: none !important; }
}
