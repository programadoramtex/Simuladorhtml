Aa Palabras que usaremos

CSS
El lenguaje que decide cómo se ve una página: colores, letras, espacios y orden de los elementos.
Regla
Una instrucción de CSS: a qué elementos se aplica y qué cambia. Ej.: h1 { color: navy; }
Selector
La parte que elige los elementos. h1 elige todos los títulos h1.
Propiedad y valor
Qué cambias (color) y cómo lo dejas (navy).
Caja
Todo elemento es un rectángulo con contenido, relleno, borde y margen.
Flexbox y Grid
Dos formas de ordenar elementos: en una dirección (Flexbox) o en filas y columnas (Grid).
Media query
Una condición, como «si la pantalla mide 768 px o más», para aplicar reglas solo en ese caso.
Contraste
La diferencia de luz entre el texto y su fondo. Si es poca, cuesta leer.

    A Una galería para cada pantalla
    
    
    Misión: los productos deben verse en 1 columna en celular (menos de 768 px), 2 en tablet (desde 768 px) y 3 en computadora (desde 1024 px). Elige los valores en el código y mueve el ancho para probar. Los bloques que se están aplicando se iluminan.
    
    
    
      
    
        
    

    /* Base: celular (siempre se aplica) */
.productos {
  display: grid;
  grid-template-columns: repeat(1, 1fr);
}
    @media (min-width: px) {
  .productos {
    grid-template-columns: repeat(, 1fr);
  }
}
    @media (min-width: px) {
  .productos {
    grid-template-columns: repeat(, 1fr);
  }
}
