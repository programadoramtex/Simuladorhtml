Módulo 1 · 10 pts

🏗️ Estructura de un sitio web

Todo sitio web tiene 3 partes fundamentales que trabajan juntas:

📄 Contenido (HTML)

Es la información: textos, imágenes, videos, formularios. Se escribe con etiquetas HTML.

<p>Hola mundo</p>
<img src="foto.jpg" alt="descripción">

🎨 Presentación (CSS)

Define cómo se ve: colores, tamaños, posiciones. Hace la página atractiva y adaptable.

p { color: blue; font-size: 16px; }

🧭 Navegación (Enlaces y menús)

Permite moverse entre páginas usando <a href="..."> y <nav>.

🏛️ Estructura básica HTML5

<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Mi página</title>
  </head>
  <body>
    <header>Encabezado</header>
    <nav>Menú</nav>
    <main>Contenido principal</main>
    <footer>Pie de página</footer>
  </body>
</html>

💡 Tip: El meta viewport hace tu página adaptable a móviles.

Módulo 2 · 10 pts

🎬 Multimedia y ♿ Accesibilidad

🖼️ Imágenes

<img src="logo.png" alt="Logo de la empresa" width="200">

⚠️ Importante: El atributo alt es obligatorio. Describe la imagen para personas ciegas y cuando la imagen no carga.

🎥 Video y 🎵 Audio

<video src="promo.mp4" controls width="400">
  Tu navegador no soporta video.
</video>

<audio src="musica.mp3" controls></audio>

El atributo controls muestra botones de reproducción.

♿ Accesibilidad web

Hacer una página accesible significa que todas las personas puedan usarla, incluyendo quienes tienen discapacidad.

  • Usa etiquetas semánticas: <header>, <nav>, <main>, <footer>
  • Siempre pon alt en imágenes
  • Usa <label> en formularios
  • Contraste adecuado entre texto y fondo
  • Atributos ARIA cuando sea necesario: aria-label, role

📱 Diseño adaptable (Responsive)

Una página adaptable se ve bien en celular, tablet y computadora. Claves:

  • <meta name="viewport" content="width=device-width, initial-scale=1.0">
  • Usar unidades relativas: %, em, rem, vw
  • Imágenes con max-width: 100%
  • CSS Media Queries para distintos tamaños

📝 Formularios y privacidad

📋 Estructura de un formulario

<form action="/enviar" method="POST">
  <label for="nombre">Nombre:</label>
  <input type="text" id="nombre" name="nombre" required>

  <label for="email">Correo:</label>
  <input type="email" id="email" name="email" required>

  <label for="edad">Edad:</label>
  <input type="number" id="edad" name="edad" min="1" max="120">

  <button type="submit">Enviar</button>
</form>

🔤 Tipos de input comunes

  • text - texto libre
  • email - valida formato de correo
  • password - oculta lo escrito
  • number - solo números
  • date - selector de fecha
  • checkbox - casillas de verificación
  • radio - selección única
  • file - subir archivos

📄 Select y textarea

<label for="pais">País:</label>
<select id="pais" name="pais">
  <option value="pe">Perú</option>
  <option value="mx">México</option>
</select>

<label for="msg">Mensaje:</label>
<textarea id="msg" name="msg" rows="4"></textarea>

🔒 Privacidad y validación

  • required - campo obligatorio
  • autocomplete="off" - evita que el navegador guarde datos sensibles
  • Usa method="POST" para datos sensibles (no se ven en la URL)
  • Nunca guardes contraseñas en texto plano
  • Usa HTTPS en sitios reales (candado 🔒)
  • Avisa al usuario qué datos recopilas y por qué

Módulo 4 · 10 pts

🌐 Publicación de tu página

📤 ¿Cómo publicar una página HTML?

Para que otros vean tu página en internet, necesitas:

  • Dominio: el nombre (ej: mipagina.com)
  • Hosting: servidor donde se guardan los archivos
  • Archivos: tu .html, imágenes, CSS

🆓 Opciones gratuitas para estudiantes

  • GitHub Pages: subes tu código a GitHub y se publica automático
  • Netlify: arrastras tu carpeta y listo
  • Vercel: ideal para proyectos modernos

✅ Antes de publicar, revisa:

  • Valida tu HTML en validator.w3.org
  • Prueba en distintos navegadores (Chrome, Firefox, Edge)
  • Prueba en móvil y computadora
  • Verifica que todas las imágenes carguen
  • Revisa la accesibilidad (lectores de pantalla)
  • Comprime imágenes para que carguen rápido
